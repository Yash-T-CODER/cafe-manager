# ☕ Py Café: Console-Based Food Ordering System in Python

A simple and interactive **Python-based food ordering system** for a fictional café. This CLI tool allows users to view a menu, place multiple orders, and receive a total bill — all through a fun, terminal-driven experience.

---

## 🚀 Features

- 🧾 Display a live menu with prices
- 🛒 Let users place multiple orders
- 💰 Calculate and display the total bill
- ⏱️ Realistic time delays to simulate live interaction
